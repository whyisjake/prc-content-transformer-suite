# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately via GitHub's [Security Advisory](https://github.com/pewresearch/prc-content-transformer-suite/security/advisories/new) mechanism, or email **webdev@pewresearch.org** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge your report within 72 hours and work to provide a fix or mitigation as quickly as possible.

## Credential exposure

If you discover committed credentials (API keys, tokens, passwords), please report immediately. We will rotate the affected credentials and force-push to invalidate history if necessary.
